# Woordenlijst

| Term | Betekenis |
|---|---|
| Agent | Het AI-onderdeel dat bronnen leest en voorstellen maakt. Stelt voor, beslist nooit zelf. |
| Bron | Een gekoppelde tool waaruit de agent leest: Gmail, Slack, Google Calendar, Asana, Google Drive, Notion, Canva. |
| Sync | Eén leesronde van de agent over alle bronnen. |
| Voorstel | Iets dat de agent aanbiedt om te beslissen: een *volgende stap* of een *nieuwe to-do*. |
| Volgende stap | Voorstel voor een actie: mail, Slack-bericht, uitnodiging of Notion-pagina. |
| Nieuwe to-do | Voorstel voor een taak die na goedkeuring in Asana komt. |
| Beslissing (op een voorstel) | Uitgevoerd, In Asana, Genegeerd, Afgewezen of Later. |
| Wat brandt | Blokkade die het team tegenhoudt en voorrang krijgt in de focusronde. |
| Opvolgen | Teamlid van wie al even geen update kwam. |
| Focusronde | Geleide dagelijkse ronde in vier stappen: Wat brandt, Beslissen, Opvolgen, Je dag. |
| Project Hub (scherm) | Detailpagina van één project met tabbladen Overzicht, Beslissen, Taken, Team, Context. |
| Gezondheid | Status van een project: Op schema, Aandacht nodig, Kritiek. |
| Fase | Een van zeven projectfases: Intake, Analyse, Design, Development, Testing, Livegang, Nazorg. |
| Koppeling per project | Welke Asana-project, Slack-kanaal, mail-label, agendatitel, Drive-map, Notion-pagina en Canva-design bij een project horen. |
